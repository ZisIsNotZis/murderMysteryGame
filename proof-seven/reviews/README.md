# 第七次校样 审阅与验证

日期：2026年11月13日。本轮写作已收尾，当前文本定稿，未真人试玩。本目录的代理审阅与知道答案的排程，不是盲测，也不证明真人会感动、兴奋或愿意玩到某个分钟数。

## 哪些设计被挡下了

[初次审查](initial.md)否决了早封套与录音结构：六人的正常记忆能直接反驳“共同确认”，断字只有装饰作用，假纸还没解释怎样帮凶手脱罪。相关失败稿保留在[工作档案](../../.scratch/third-script/rejected-structure/design.md)，没有删掉当作从未发生。

当前纸层与全体真实不在场的结构，是在这次否决后重新做的，不继承初稿的证明。

## 当前材料的检查

- [正式证据审查](evidence-review.md)：核纸层、时间上界、B17来源与闭合机会，推动加入初始可查的P17，而非结尾认罪。
- [最终独立审查](final.md)：审阅者未写角色或成品正文，核空间、人物路径、亲批与活人端点、分发及情感责任。
- [合作路径与实物推演](playthrough.md)：写过部分角色且知道答案的作者，核全公开、问孟快解、纸层、图边与数字折页。不是独立玩家试玩。
- 静态交付工具检查六角色、17证据、8散页、5工作台、1追加本、分发材料与链接；不声称能测故事质量。
- 对前两部57个已有文件进行SHA256基线复核，原故事、打印稿、档案均保持内容不变。

| 侧间、装订台路径会破P17 | 两者明确在前区；后区只有走廊和校对室，沈从前厅入口看梁，不入走廊 |

独立报告保留审阅时指出的问题；上述同步项已在生产稿修正，不把历史报告删掉伪装零失误。

## 仍然没有证明的事

NPC真凶仍可能被元猜；孟的直接解释与P17会使快桌很早解开，不能靠藏材料补难度。本作应按短物证还原加作品创作定位，不宣传高难长篇推凶。后段兴趣来自核对、更正、亲情与亲手做书，是否足以支撑整桌，需真人判断。

数字图层、图边与排样已经检查，不等于真打印机双面折过每张纸。打印说明允许手工对折贴卡，避免把设备翻页方向当谜题。网页画面预览的范围另记，不冒称完整纸张逐页印刷验证。

首场真人最应记录：早解后还想做什么；纸层是自己发现还是仅听解释；谁真正参与了现场图与作品；从追责走向归还名字是否自然；私信选择是否有压力。若再次变成开会，就改最先令玩家退出行动的环节，不能只添更多规则或感人台词。
