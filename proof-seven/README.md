# 第七次校样

六人合作还原与创作剧本。你们来旧印坊讨回一个名字，却遇到所有人都有真实不在场证明的命案。一张经过两次印刷的校样，会改变“最后见到活人”的判断；一册被改署名的旧书，也等着有人把它接回原来的路。

**文本定稿：2026年11月13日。** 本轮写作、材料整理与审阅已完成，当前收尾。

这是系列第三部，题材、人物与前两部独立。预计90—120分钟，快桌可60—90分钟；尚未真人试玩。定位为短物证案加合作拼册与亲情故事，不冒称复杂长篇推凶。谜面可以被直接询问快速拆开，规则接受早解。

- 想快速知道剧情：[剧透速览](story-overview.md)。
- 先感受现场：[开场样段](opening.md)；[三分钟纸层原型](prototype.md)含纸层答案。
- 玩家先读：[入场页](player-guide.md)与自己的[角色本](characters/)。
- 主持人准备：[手册](host-manual.md)、[共享桌面](scene-board.md)、[证据](evidence.md)、[工作台](stations.md)、[散页](workbook.md)、[追加记忆](recollection.md)、[结局](endings.md)。这些包含剧透。
- 打印：[玩家册](print/player-materials.html)、[主持人册](print/host-materials.html)、[独立分页分发册](print/handouts.html)、[两张纸四面的八页排页样稿](print/booklet-layout.html)。Q03先交陆芹与许柚，私人末页默认另封。
- 看验证与限制：[审阅记录](reviews/README.md)。事实权威是[设计底稿](design.md)，早期被否决的结构保留在工作档案。

剩余最有价值的改进来自真人试玩：早解后是否愿意继续、拼册是否自然、情感是否有压力。未出现具体反馈前，保持当前文本。

改源稿后运行 `node tools/build-proof-seven.mjs`；交付检查运行 `node tools/check-proof-seven.mjs`。无需安装依赖、联网或真印刷设备。
