# 《寿宴》——6人民国家宅剧本杀

> 设计总纲见 `idea.md`（设计宪法）。本剧本是宪法的完整落地实现：
> **误导不来自作者隐瞒，而来自玩家自己的默认假设。**

## 玩家人数与时长
6 名玩家 + 1 名主持人（DM），150–180 分钟。

## 双层诡计（剧透警告）
- **主诡计《死亡在下午》**：全篇不声明死亡时刻。玩家默认"发现（20:30）≈死亡"，所有行踪与不在场证明被锚在晚间；真相是死者死于当天下午未申之交（约15:00），晚宴全程人已死，晚间每场"冲突"都是死讯后的余波。凶手的诡计全部由公开真话构成——他那份全桌签字的晚间不在场证明，恰恰是"全桌都没看见下午"的反证。
- **副诡计《一人双职》**（复盘第二层）：仆役老陈兼管家与园丁两职。全篇从不断言"管家园丁是两人"，玩家按"职务数=人数"的人事图式自行多算一人。
- 每一句文本在表层读法与真相读法下**都字面为真**。全篇角色零谎话。

## 验证记录（agentic 流水线）
1. **红队审计**：公平性/结构/表层三路 spec 级红队（1×P0 修复）＋成稿后三路一致性审计（指称/违禁句全零、22条映射双读真值全过、M/S/K 台账 23 条全部落位）。
2. **盲测 1（普通桌）**：无人提前翻面（表层普通性成立）；凶手仍被 4/6 票正确指认（K链真话推理）；副诡计幻影园丁存活约3分钟被合并；仅2次轻度流程救场。
3. **盲测 2（老手桌）**：提前翻面路径成立（第②阶段凭尸温换算翻面），翻面后 K 链仍需第二轮搜证合龙；主持人分支(a)「抽验确认」实测可用。

## 已知边界
- LLM 盲测不等价于真人实测；建议实桌 1–2 场后按 `.scratch/blindtest-*.md` 的观察维度复盘。
- 卡面文案为精简版，实体化时可扩充美术与质感，但**不得增删事实句**（见 spec §7 写作规范锁）。
