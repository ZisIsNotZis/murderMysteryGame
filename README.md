## 第七次校样 快速入口

本轮写作与材料整理已于2026年11月13日收尾，当前文本定稿。后续若有真人试玩反馈，再按具体问题修订；不继续为增加复杂度而扩写。

六人来到旧印坊追讨被侵占的作者署名，顾砚生却遇害。所有人在关键晚时段都有真实不在场证明，一张带他真批注的校样又似乎证明他当时还活着。玩家得亲手拆开印刷与批注的先后，再查谁在真正的案发窗口进入后室。

表面来清算一个名字，最后也要归还几个名字：原作者的署名、另一位被诬者的名誉，以及决定一封私人家书是否公开的权利。伤害不被洗白，合作也不等于所有人的过去都没错。

- 想先感受：[开场样段](proof-seven/opening.md)／[三分钟实物谜面](proof-seven/prototype.md)。

六人加一主持人，预计90—120分钟，快桌可更短。定位是短物证还原加合作拼册，不冒称高难长篇推凶；趣味、难度与时长尚待真人验证。

## 持续遵守的约定

作者不撤回已确认事实；人物的绕路要有处境和性格上的理由。允许合理主观认知、局部失忆和探索触发追加本，不能把它们当随时补答案的工具。允许直接问、全公开、报警、早解与更简单的方法。坏人的欺骗可查，善意角色不为维持谜题降智。
