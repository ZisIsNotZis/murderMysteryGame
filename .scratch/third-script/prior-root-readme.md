# 请把船开回来

六人合作剧本杀，冒险与温情并存。旧拖船退役前夜，船长遇害，七位工友又被风雨留在外港平台。你们要查明发生过什么，也要亲手安排他们怎样回来。

六名玩家同队，凶手在NPC中。没有秘密敌对任务、不强制撒谎或保密、不按玩家猜错或讨论慢惩罚人命。角色可以有旧伤和意见差异，行动、岗位和未来都由玩家自己选择。

当前是**可开桌的完整初稿，已做文本审查与规则推演，尚未真人试玩**。预计120—150分钟，快桌约90分钟；时长与实际趣味仍待验证。适合希望一起解决事情、喜欢人物关系、能接受适度悲伤的玩家。

## 从这里开始

- 想先感受故事：[前十分钟样段](harbor/opening-sample.md)，不含凶手解答。
- 准备做玩家：[玩家入场页](harbor/player-guide.md)，随后只读分配给自己的[角色本](harbor/characters/)；愿意共享时可互相传阅。
- 准备开桌：主持人先读[主持人手册](harbor/host-manual.md)，按其清单准备[桌面板](harbor/table-board.md)、[行动卡](harbor/action-cards.md)、[证据卡](harbor/evidence-cards.md)和[结局](harbor/endings.md)。后三者含剧透，玩家开局前勿通读。
- 直接打印：打开[玩家打印册](harbor/print/player-materials.html)、[主持人打印册](harbor/print/host-materials.html)和[可分发卡片册](harbor/print/handout-cards.html)。卡片独立分页，剥离了主持人答案；由主持人按规则发放，玩家开场前勿通读。改源稿后运行 `node tools/build-print.mjs` 可重新生成。
- 想看创作决策与验证：[设计底稿](harbor/design.md)、[审阅与验证记录](harbor/reviews/README.md)，均含剧透。

## 游戏里会实际做什么

三个行动窗口，六人结伴完成九项场景行动。拖船接驳与岸线接应各有完整路线；玩家摆港图、分接应车辆、交接值守、点七人的名字、保全原始记录、把工具和小厨房搬回有去处的地方。已有材料和电话查询免费，不靠猜搜证入口制造难度。

案件可以提前查出，也可交警方继续处理。查案不会锁住接应；结尾根据实际完成的岗位、物件和约定回应玩家。船可以继续争取值守，也可以退役、让岸台与人的往来留下。没有强迫原谅、继承或留港的标准答案。

包含亲人遇害与旧事故责任，不演死亡、不展示遗体、不要求情绪表演。可略过相关段落或调整亲属关系，见入场页。

## 旧稿与项目范围

本项目是一次性写作项目，不是自动生成剧本的软件。旧作《寿宴》连同设计、审查、LLM模拟记录和原README完整保存在[旧版归档](archive/README.md)。保留它，是保留走过的路；新版不继承“全员零谎话”以及旧版自称通过体验验收的结论。

后续修订以真人一桌的实际选择、卡顿与感受为依据，不把独立代理评审叫作盲测，不用虚构的玩家兴奋或哭泣证明故事好。
