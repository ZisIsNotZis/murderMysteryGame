# 合作路径桌面推演

日期：2026年11月12日。性质：依据规则和材料逐项排程的作者桌面推演，不是盲测、真人试玩或体验测量。

我参与了林照、周渡、陈雁三本角色本的写作，读过设计底稿，知道幕后答案。本次完整读过玩家入场页、桌面板、行动场景卡、主持人手册、证据卡与结局。因此下文只核查行动能否排出、证据是否可得、成果是否有对应回应，不以“玩家一定会这么想”或虚构的笑声、感动与兴奋证明效果。六本角色本此前已完整读过。

## 一 核查办法与边界

用六名玩家姓名逐窗分队。每个表格单元只占一个行动槽，同一真人同窗不出现两次。查阅已存在的材料、电话核实和递交判断不收费。若写了A06或A07，另行记它真正完成的封存、整理或现场走访成果，不把关键证据的取得记成该行动的奖励。

三个正常双人队排程中，每窗均为三项、全程九项。角色未做的侧行动，不在结局补勾。主路线在第三窗末才实际接人，提前完成A05不提前移动七人的姓名牌。

以下表格简称：林＝林照，周＝周渡，陈＝陈雁，何＝何雨生，许＝许青禾，唐＝唐穗。

结局应选“拖船接驳完成”。出航岗位可给周，岸线联络给陈，港务协助专业操作；两段岗位都应被点名。随后依次兑现A08、A09、A10、A12、A13：工具交物、陈小满到准备好的位置、六件东西照本人去向、周遥收到已约定的材料、厨房器具放到面馆寄存角。没有A06、A07、A11，不能补读共同封存、现场走访或合照成果。若玩家免费完成了案情判断，仍可提交，但不能冒领未做的现场工作。

**灯塔判断：可行，结算措辞缺口已修。**初读时A02允许“待A03”，同时“完成与回声”又直接写放“接驳方案就绪”，容易提前勾选。我报告后，行动卡总规则与主持人手册明确三队同窗统一结算：A03完成则等待中的A02转就绪，否则只记待引导或改直达路线。已读回核对，以上第一窗排程成立，不收第二次A02费用。

## 五 完全不查命案并且不开旧船

角色明确请警方接手谋杀调查，E卡收到后放旁边，不做A06、A07，也不要求大家发表判断。旧事故更正是角色后续生活事务，若也不想处理可换其他侧行动。

结局选“岸线接应完成”。命案部分只用警方后续简报；玩家不想听完整讲解时简报可以止于已锁定调查方向。没有A06/A07，不念相应回声。不开船仍有九项实质动作，可观察的是两灯、排车、厨房落地点、七人清点、安顿位、工具交还、物件去向、合照构图、回访安排。

更极端的拒绝路线：全体从开场就选等专业队并不参与，三个窗口可以简述跳过，读默认接应，七人照常回来。不补九项成果，不羞辱玩家，也不把这条退出路线描述成经过验证同样有趣的玩法。

## 六 无人愿跟林照配队与三项上限

**发现过算术冲突，现已修复。**初读版规定六名真人严格组成三支双人队；林照与NPC助手占一队后，余下五名真人只能进入另外两支双人队，容量四人。至少一人失去行动，或必须开第四队。仅写“助手补位、不增加槽位”不能解决这个容量问题。

报告后，玩家页、行动卡、主持人手册与设计底稿已经明确：双人为默认，行动队允许1—3名真人，每窗最多三队、每人只参加一队；单人可有NPC助手。已读回核对。这样不需要强迫谁和林照组队，也不需要增加行动槽。

## 七 参与是否可观察

| 行动 | 桌面上实际变化 | 尚存的弱点 |
|---|---|---|
| A01 | 三张检修牌移列，接手人拿走白板 | 几乎无方案分歧，更接近交接操作；应短演，不能拖成解题 |
| A02 | 玩家摆往返航段、发出航/联络/岸上岗位 | 有明确空间约束和两条路径；若主持人直接念标准路线，就退化为勾选 |
| A03 | 两灯放到图上，联络本交班，后续短讯接收者变更 | 两灯都要用，地点基本已给；最有意义的是谁真正接班，而不是灯的摆法 |
| A04 | 七旅客＋两接应员排入4+5座，决定先到车 | 是可验证安排；题目不难。应给安排带来第一场相遇，别额外考人凑难度 |
| A05 | 七名与物件逐项对应，同行组合与首次联络对象留下 | 容易只是点名签到，须让接收人最后真正接到联络 |
| A06/A07 | 玩家用证据构建自己的案情图与待查问题 | 有认知工作；主持人不能把卡上的完整说明再念一遍冒充调查 |
| A08/A09 | 物件去向、共用箱借还、七个安顿位置及干衣形成 | 日常照料能提供温馨，也可能显得像分拣任务；需要简短且按选择回应的NPC场景 |
| A10—A13 | 私人物件交付、照片构图、本人更正要求、厨房新落点 | 未来安排确有差异，但多数仍是登记。实物交付和回信应落实，不宜全部停在写表 |

总体判断：新版已经有几类不同的可观察动作，明显超出旧版轮流交证词；但九项中大量属于安排、登记与交接。它目前更像一场有命案的合作接应夜，冒险强度较低。不能仅因为不对抗、不死人，就认定温馨自然成立。真人样段应重点观察A01/A03/A05是否过于机械，以及玩家是否真在等待自己安排的返港回应。

## 八 修订结果与未验证项

3. 已修：A10其他人回复物件去向是免费回应，不算第二场行动。
4. 已修：A09结局优先执行玩家确认的首处安顿与座位，不用默认叙述覆盖安排。
5. 已修：A10周渡“旧船票”改为角色本已有的空保温杯，没有为了迁就误写新增道具。

上述“已修”针对相关文件的明确规则，分组、同窗结算与既有物件做过读回。其他文字变化由主作者继续核对，不把本次排通的同一路线反复包装成新的试玩次数。
