## 做过什么

- [初次独立因果审查](causality-initial.md)：指出攻击证据缺环、行动像勾选、路线无具体操作、信息查询与行动成本混淆等问题。
- [最终独立因果审查](causality-final.md)：审阅者未写成品正文，复核案件、直接办法、证据可达性、默认接应与成果处理。
- [合作路径桌面推演](tabletop-walkthrough.md)：角色作者明确知道答案，逐窗排出拖船、岸线、快案、零调查、单人助手五条路径；只证明这些示例能运行，不虚构玩家感受。
- `node tools/check-manuscript.mjs`：检查六本角色、十三张行动、十二张证据、链接、五套排程的行动数与路线前置、1+2+3分队算术。是静态交付检查，不是游戏体验测试。
- 旧版归档按Git原始blob逐文件核对，35个被归档的原跟踪文件内容保留；许可证和忽略文件仍在根目录。
