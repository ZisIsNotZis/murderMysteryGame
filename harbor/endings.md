# 请把船开回来 返港与结局

主持人用，含案情。第三窗口结束后使用，约十五至二十分钟。先按桌面执行返港方式，再回放实际做成的侧行动，处理案情，最后让六人留下自己的去向。无需每人发表演说；玩家一句话、一个动作、写一张纸或不回应都可以。

## 一 先让七人回来

先读共同段，再从三条路线中只读实际发生的一条。把七张姓名牌移到岸台；采用A05清点表或A04分组的，依玩家排定顺序移动，不擅自替换安排。

**共同段**

风还没有停，岸台的玻璃上挂满细水。无线电里有人试着报了一遍栖湾港的名字，信号清楚了。

“这里是接应艇，已经到位。平台七人都在。”

那边有七个声音，彼此让着话头。王澈说橘子还有，赵桂芳提醒他别把袋口弄开。没有人再需要用一句笼统的“那几个人”称呼他们。

### 拖船接驳完成

“归来”按你们确认的路线到了平台西侧。驾驶和接驳由有资质的人员依方案完成；岸台上，留下的人能从联络里听见每一段交接。

七人按你们安排登船。董宁先站稳，伸手接过后面递来的袋子。陈小满回头看了孙苇一眼，两人都点了头。最后一张姓名牌翻过去，平台交接结束。

返港时，船头那两个字从雨里慢慢显出来。码头上已经有人把接应的位置让开。船靠妥，七个人陆续走下来。岸上、船上的工作，到这里接在了一起。

### 岸线接应完成

专业艇在平台西侧接上七人，驶向你们选定的岸线接应点。引导灯在雨里亮着，两辆车按排好的位置等候。按A04分组，把旅客与接应员姓名牌放进各车；没有谁被临时换下。

陈小满在车门前先看了看接应名单：“是这辆，对吧？”孙苇给她让出半步。另一辆车上，董宁接过王澈抱着的橘子。门关好，车里的人才开始说起平台上的雨有多横。

两辆车先后回到岸台。有人已经从门口认出何雨生的背影，隔着车窗敲了两下。你们留在岸上的这一段路，也把七个人完整接了回来。

### 专业队执行默认接应

港务接班人员与专业艇完成了联络、清点和岸线接送。岸台收到一条简短确认：“七人齐，正在返港。”

车到门外，董宁提着自己的袋子先下来，陈小满从另一侧绕过来找姐姐。专业队把接送记录放到桌边，去做后续交接。你们可以上前，也可以先坐在灯下等对方走近。

若玩家只做了部分准备，准确补上一句：“你们完成的____已经交给接班人员使用。”不把这些准备说成白费，也不把整趟接应归为玩家独立完成。

## 二 看看什么跟着回来了

看成果区，只执行已完成的A06—A13；没有完成的项目不读对应回响。未选物件按行动卡交港务暂存或次日清点，不突然损毁，不自动补成全部成果。专业队的基本接应和保暖始终存在。

| 完成项目 | 移动物件与短场景 |
|---|---|
| **A06 保全记录** | 把案情重建与封存回执放进交接袋。港务值班员在副本写下接收时间：“原件在哪里、哪些还没核，你们都标了。我按这份交。”玩家自留副本；这不是定罪证明。 |
| **A07 到访者核对** | 将来往时间图放在警方资料旁。值班员划去图上已经排除的疑问，圈出玩家提出的具体核查请求：“这一项我带去问，不把你们的猜测写成见闻。”保留玩家自己的标注。 |
| **A08 取回工具** | 按交还名单把七个挂牌工具包与共同工具箱移给主人。蒋柏逐一对登记牌，梁一帆接过自己的包，先摸了一下常放笔的口袋。董宁说：“明天不用先找人借一套了。”东西确实回到了各人手中。 |
| **A09 热汤与干衣** | 按玩家安排摆七个安顿位置、干衣包与饭碗。赵桂芳在玩家与她确认的位置坐下，把饭盒放稳。王澈问能不能把橘子分了。董宁找到何雨生，先问葱还在不在；若有人带来保温壶，她敲敲壶盖：“这回盖子没丢。” |
| **A10 船上的六件东西** | 按去向牌逐件交付或封存，不把所有物件都送回船上。交给人的，请收件人接一下；交港务的，贴好名字。物件主人可以更改自己的决定。旧东西跟着人走，不替人签下留港的承诺。 |
| **A11 最后一张合照** | 按玩家的构图摆姓名牌或实际站位，保留题名和收件人。愿意入镜者入镜，不愿意的可拍照、递纸或休息。主持人说：“按这个样子拍到了。副本送给你们写下的人。”照片不自动成为所有人的共同宣言。 |
| **A12 给周遥打电话** | 把周遥本人确认的更正要求附到旧记录后。只复述行动中已得到的答复，不增加原谅。若他允许回信，可读：“更正的给我一份。别替我写没关系。”若玩家选择代收或暂不谈，材料按约定送达即可。 |
| **A13 搬回小厨房** | 把锅、炉具、长凳移到玩家选定的落地点，留下保管人。邀请下一顿饭时只记自愿答应的人。返港者走近看了一眼，有人问：“这口锅也搬来了？”主持人把下一顿饭的时间留给玩家写，不替大家定下永久值守。 |

没有A09时，返港者接受专业队的基本安顿；不出现已经替七人安排好的私人座位与散伙面。没有A13时，锅、炉具与长凳仍按暂存安排保管；不能在结尾忽然读出“小厨房照常开张”。

## 三 把案情交到下一双手里

让愿意的人用桌上材料说明判断。可以由一人说、多人补，也可直接递交文字。主持人只核对证据支持了什么，不要求说出19:14这个作者知道的精确分钟。

### 玩家已有完整或大体完整的重建

港务值班员接过材料：“你们交来的记录，把几件事接上了。”

按实际内容回认：19:12船长仍在实时通话，19:18被发现；潘声称19:05已走，却有19:13收条、上船见证与19:22乘车记录；藏起的信号槌与蓝纸角、文件夹缺口相连；两版结算表和十二万元流水解释了冲突；19:16文字消息不能证明发信人就是船长。攻击的现场依据以已公开的E07为准。

“这些材料支持把潘启明列为重点调查对象。你们标出的待查项也一并接收。”

未说到的环节若仍影响判断，就在副本上保留待查，不偷偷替玩家补成全对。正式鉴定、讯问与后续处理由警方负责，不安排潘突然在电话里自白。

### 玩家只查了一部分或把调查交给警方

警方后续简报：“已核的到访记录、现场副本与结算材料，目前指向潘启明。我们正在核实其行踪、资金去向与攻击经过。”

只用桌上已经提供的E01—E10说明关键联系，不在结局发一张此前拿不到的决定性证据。明确这是警方继续调查所得的简报；玩家已经提供的见闻、求助与核对，分别记入，不称“你们成功破解了全部案情”。若全桌不想听案件讲解，读到此处即可。

**账款后续**

何雨生18:50签收的六万元工资仍独立封存，按核对名单交付，不因报警或停交接取消。归港金总额十八万元中，另十二万元过渡安置款去向正在追查；保全记录有助后续追索，但今晚不能宣布已经追回，也不能宣布永远拿不回来。给接手人留下联系与回执。

六年前的事故说明、更正底稿和相关要求另袋保存。林守川今晚被害，不取消他过去的责任；今晚的合作也不替周遥签一份原谅。

## 四 船的未来留一张可以接着写的纸

拿出新纸，写一个当前方向、下一位愿意联系的人和一件尚待核实的事。三条方向都可成立；不能达成一致就分别记录意见，不强行投出唯一情感答案。

**争取继续公益值守。**依补充条款申请七天复核，暂缓交接，去核算检修、资质、资金和排班。可以写下哪些人愿参加商议；“愿商议”不等于保证捐钱、辞职或接班。今晚完成接应，不能替代未来运行条件。

**按约退役，留下岸台与小厨房。**继续核工资和过渡安排，商议联络点、锅、炉具、长凳与聚餐由谁保管。A13做成的厨房物件已经有了落地点；未做的，先列搬运和使用许可待办。不把退休称为放弃救人，也不虚构一艘无需花钱维护的永远待命船。

**暂不决定，交专业机构接续。**把工作清单、值守记录与返港者需要交港务及相关机构，约定七天内的联系人。每人可以先回到自己的生活，之后再决定参与多少。“今晚不决定”也可以留下可靠交接。

## 五 六封可选择的回信

以下小段可分给对应玩家。回一句、做个动作或不回复均可；不要要求玩家说出预设情绪。个人离港不影响已完成的成果。

**给林照**

交接纸递到你面前，没人把笔塞进你手里。你的维修本放在一边，面谈通知还在自己的东西里。有人问：“明天要帮你把哪一箱搬走？”你可以指定一个箱子，可以说暂时不搬，也可以把问题留到明天。父亲的工作与错误，不会自动成为你的全部余生。

**给周渡**

周遥发来消息：“到了就回个话。”你可以告诉他七人已经返港，把更正材料按约定送去。你也可以只回一句“我到了”。今晚你能接过一段工作，而不接过师父所有的做法；哥哥愿不愿谈旧事，由他自己决定。

**给陈雁**

陈小满走到联络桌前，指了指空着的位置：“你坐一下？下一通我先帮你喊人。”你可以坐下，可以再核最后一条记录，也可以把本子交给别的同伴。联络还会继续响，这一班不必只有你接。

**给何雨生**

董宁把袋子放在脚边，伸手来拿壶。她说：“明天工具的事，吃完再说。”你可以递壶、分橘子，或者请她再与你对一遍工友的安排。代表大家不等于替大家答应一切；你自己的那碗饭，也有位置。

**给许青禾**

交接袋合上前，值班员指着你写的“待核实”问：“这一项，联系谁？”你能给出名字，也能留下自己的联系方式继续问。旧便笺可以留着或收起；这回没有核完的地方，没有被你写成已经结束。

**给唐穗**

有人在那把背风的椅子上坐下，问下一张标签写什么。你可以把笔递给对方：“写你自己的名字。”也可以请同伴陪你收这一桌东西。之后上船还是留岸，你还有时间选；今晚已经有人接住你伸出去的手。

## 六 收灯

按完成的成果保留桌面，最后读：

“七张姓名牌都回到岸边。还有几张纸没填完，几件事等明天继续。门外的人把雨衣挂好，进来找自己认得的人。”

若做了A09或A13，可再读：“有人问水开了没有。”否则读：“岸台的灯还亮着，回家的车也在等。”

停在这里。不为今夜加一句全员和解，也不替他们把明天写完。
